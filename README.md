# Common Ground

An informational product and culture website concept for Halfway House, Midrand.

## Requirements

- Node.js 20 or newer

No npm packages are required.

## Local development

Run: npm run dev

The site is built and served at http://localhost:4173. Changes inside src are copied into dist automatically.

## Production-style run

Run npm run build, then run npm start.

To use another port, run: node scripts/serve.mjs --port 4174

## Checks

Run: npm test
